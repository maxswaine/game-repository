Notes for the reviewer, to accompany our response for What's That Game.

What's That Game is a community platform for finding and sharing games with friends and family, for any occasion. It's built entirely from user submissions, not a fixed content pack, spanning 12 categories (Card, Dice, Trivia, Word, Physical, Strategy, Guessing, Acting, Drawing, Music, Other, Drinking). Contributors add games they actually play, so the catalogue grows and diversifies over time, closer to a shared, crowd-sourced game library than a bundled set of prompts.

In our own research we haven't found another app doing crowd-sourced game knowledge to the extent of What's That Game.

AI-ASSISTED RULE CONTRIBUTION

A lot of people know a great game but won't submit it if writing it up formally feels like work. Our AI-assisted contribution flow lets someone write (or dictate, using their phone's own voice-to-text) a rough, freeform description of a game, and our AI automatically structures it into the fields every game needs: objective, setup, and rules. This is a major reason our library has real, thoughtful, well-described games rather than a shallow list.

CLEAR, ACCESSIBLE RULES

Every game follows the same structured layout (objective, setup, rules, difficulty, duration, player count), so rules are easy to scan and consistent regardless of who submitted them. Contributors can also attach ordered setup photos, so for a game with a fiddly card or board layout, players can see exactly how it should be laid out before starting. An AI rules optimiser is also available to tighten unclear phrasing before publishing.

SEMANTIC SEARCH

Rather than just filtering by category, users can describe what they want in plain language, for example "a quick card game for 4 people with no equipment," and the app ranks the library by actual relevance, not just keyword matching, while also applying hard constraints like "no equipment" directly. This is what makes the app genuinely useful for its stated purpose, finding the right game for an occasion, rather than just a static list to scroll through.

GUIDELINE 5.1.1(v) — COUNTRY OF ORIGIN

We've updated the app so Country of Origin is no longer a required field. Signup and profile forms accept account creation/update without it, and backend validation treats it as optional — no request is rejected for omitting it. Existing users with no value set are unaffected.

Country of Origin remains available as an optional field for users who choose to provide it, e.g. to show where the games they've contributed originate from around the world. It is not used to gate access to any core feature of What's That Game.
